Why ASC?

Attention reads KV cache in a scattered, score-dependent pattern. DRAM prefetchers are designed for sequential access. The mismatch wastes up to 84% of memory bandwidth.

Problem: Scattered Reads

Attention scores create a data-dependent access pattern. On RTX 4060, scattered reads achieve only 4-14 GB/s vs 56-92 GB/s sequential — a 5-35x penalty.

Solution: Predict + Prefetch

PAR (3-layer MLP) predicts which KV blocks will receive high attention. Prefetch queue loads them into L2 cache via high-priority CUDA stream.

Result: Bandwidth Recovery

When KV cache resides in DRAM (70B+ models), ASC converts scattered DRAM reads into sequential prefetch, recovering 35-40% bandwidth.

Quick Start

pip install -e .
python manual_tests.py          # 51/51 library tests
python run_tests.py             # full benchmark suite

Python

from asc import PredictiveAttentionRouter, DRAMBenchmark
import torch

par = PredictiveAttentionRouter(d_model=1024, n_blocks=32, top_k=8)
idx, logits = par.predict_blocks(torch.randn(1, 1024))
print(f"Blocks: {idx[0].tolist()}")

r = DRAMBenchmark.measure_bandwidth(128, "sequential")
print(f"BW: {r['bandwidth_gbps']:.1f} GB/s")

C++

#include "par.hpp"
asc::PredictiveAttentionRouter par(1024, 32, 8);
std::vector<float> h(1024, 0.5f);
auto r = par.predict(h.data());
